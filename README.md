# JOGO DA VELHA – MIPS Assembly (MARS)  
Implementação do clássico **Jogo da Velha (Tic-Tac-Toe)** utilizando **Assembly MIPS**, no simulador **MARS**. Projeto para a disciplina **Infraestrutura de Hardware**.

---

### Propósito do Projeto  
Este projeto foi criado para:

- Praticar lógica de programação usando **Assembly MIPS**.  
- Exercitar leitura/escrita, loops, arrays 2D e controle de fluxo.  
- Criar um mini-projeto organizado com boa estrutura e clareza.  
- Desenvolver um jogo completo e funcional no MARS.

---

### Objetivos do Projeto

- Representar o tabuleiro como matriz 3×3 na memória.  
- Ler jogadas do usuário (linha e coluna).  
- Alternar entre jogador **X** e **O**.  
- Validar jogadas e impedir sobreposição.  
- Verificar vitórias em:  
  - Linhas  
  - Colunas  
  - Diagonais  
- Detectar empate (tabuleiro cheio).  
- Exibir o tabuleiro após cada jogada.
